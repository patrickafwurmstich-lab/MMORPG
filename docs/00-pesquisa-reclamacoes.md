# 00 — Pesquisa: o que os jogadores reclamam

Base para o design. Cada reclamação vira um **problema que o sistema precisa resolver**.

| # | Reclamação recorrente | Onde aparece | Problema de design |
|---|---|---|---|
| R1 | "Endgame é o jogo de verdade"; o resto vira corredor | r/MMORPG, MeinMMO, MMOGames | Progressão que só aponta para um lugar |
| R2 | Build meta: só 1–2 builds viáveis por classe, expulsão de grupo por não ser meta | MassivelyOP, Tree of Savior, PoE, First Descendant | Otimização converge num único ponto |
| R3 | Itens chatos: "+5 de dano, +5%" | PoE2 | Atributos sem interação entre si |
| R4 | Tudo vira corrida de DPS | First Descendant, SAO Fractured Daydream | Chefe é só barra de vida |
| R5 | Grind e RNG puro (300 crafts e falhou) | Aion 2, Throne and Liberty | Esforço não se converte em progresso |
| R6 | Inflação de ouro (Tibia: 96 mi → 3 bi de ouro/dia em 2 anos) | Tibia, ESO, WoW | Torneira > ralo |
| R7 | Deflação por excesso de ralos (escambo em New World) | New World | Ralo > torneira |
| R8 | Guias externos acabam com a descoberta | MeinMMO (6 lendas, 2026) | Informação se espalha em minutos |
| R9 | Áreas antigas ficam mortas | Tibia, Path of Exile | Conteúdo descartável |
| R10 | Sistema que não se entende em 5–10 min faz o jogador sair | r/MMORPG | Profundidade vs. clareza |
| R11 | Toram: combate de esquiva/bloqueio funciona, mas build e loop cansam em poucas horas | Steam (Toram) | Mecânica boa, progressão rasa |

## O que SAO (1ª temporada) traz de bom
- Andar desbloqueado por quem derrota o chefe **vale para todos** — progresso coletivo, não individual.
- Cada andar é um bioma com tema próprio, e o chefe costuma ser o "rei" dos monstros do andar.
- Há chefes de campo, chefes de andar, mini-chefes e chefes de masmorra.

## Requisito central do Lucas
> Cada jogador pode ser protagonista. Ninguém olha o nível 100 e vê o próprio futuro.
> Tudo conversa entre si (status ↔ habilidades ↔ itens ↔ mundo ↔ economia).
